7. 为了继续向前，最后我没有去深究为何release模式不行，不过问题总算是解决了
8. 最后我也把我的解决方法分享在那个评论区了，希望能帮助到他人

## 二、任务经过

OpenCV库里成员众多，一时难以学完，所以我先在知乎上看了大概1/3的功能，了解其为处理矩阵类（如图片或深度学习参数矩阵）的功能后便用AI生成代码，然后根据代码学习了对应的库函数，最后对现有代码进行修改，删除了一些冗余，增加了一些功能。

提升任务部分，本来我是按照题目提示，加载完成后先转灰度图再进行阈值判断、二值化等，然而却发现实际图片中轮胎反光严重（如题图反射黄白光），而它与待分割红光区域在转为灰度图后灰度相似，作为噪声难以分离，如果提高面积的下限阈值，则由于角度问题，部分红光区域因面积过小也被一并过滤掉了，所以直接转灰度图分析这个方法效果不佳。

于是我就先转到HSV，通过限制H的值很好地分离了反光区域，也尽可能保留了待分割区域。但是我发现这只是题图轮子反射黄白光，那如果是比如瓷砖地面反射本来就偏红色的光呢？此时就需要继续调节HSV阈值，所以我在相关函数里留了参数端口，如果光影变化可以二次修改默认值，实现较好地分割效果。
