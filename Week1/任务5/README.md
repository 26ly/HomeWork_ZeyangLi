# 第五题（思路）

由于时间问题，第五题我初步给出思想：

## 一、遍历算法：

1.对于一个有边界迷宫，我们可以将边界全部设置为"T"，即若原图G1大小m*m，则输入矩阵为(m+2)*(m+2)；
2.判断起止点关系（本题中为起点左上(0,0)，终点右下(5,5)），最开始向右\向下走，每一步都按照优先级“上一步方向->（若不重复）向右\向下->向左\向上”遍历（不走回头路），如果为"T"，则找下一优先级，直到找到"O"（可走位置），确定下一步方向；
3.如遇到分叉点先存储记录该点位置，而后走优先级高的那一条路；
4.如果遇到“死胡同”，即某一步遍历所有方向（不掉头）下一步位置均为"T"（陷阱），则退回到上一次最近的分叉点，选择下一优先级的路走，并且将上次未走通的那条支路上所有的"O"（可走位置）标记为"T"，我们称这些点为“无效可走位置”，即最优路径必然不会经过这些点；
5.按照2~4的方式，如果从起点到终点至少存在一条通路，那么必然能够遍历到，最大计算量级为O(m^2)，然而考虑到陷阱存在，即可走位置的稀疏性，故最大计算量级为O(m*lnm)。同时我们还能得到一个新的迷宫矩阵G2（排除了所有“无效可走位置”后的新迷宫）；
6.新迷宫不存在“无效可走位置”，接下来便需要减少走通步数，即路线长度，那么我们这次重走之前的路，如果两条路径L1,L2经过不同路径到达某个相同的点（非终点），那么就要比较L1,L2既走长度，对较长者的非L1,L2公共部分标记为"T"，以此类推，最后会得到一组新解L1*,L2*...它们的特点是，终点相同（显然），最初可能存在重合路径，然而一旦分离后，终点之前不会再有交点，同时也会得到可走位置更加少的迷宫矩阵G3（O(G3)<=O(G2)）；
7.对G3中有限条路径直接计算长度，比较最小值，得到最优路径。（因为经过两次筛选，直接计算所有路径长度的计算量大幅降低，大概在O(lnm)~O(m)）；
