# 第四题：深度学习模型

我暑假时参加了一个中医药图片分类大赛，保留了训练好的Res50, Res101, Dense169, Vit_L_16的相关模型及微调过的参数，然而发现这些模型参数量都偏大，计算量偏高，不适宜移植，也不符合题目要求，于是我就直接在当时Res50的源码上稍作修改重新train了一个Res18，由于时间问题，我没有继续尝试MobileNet等更加轻量化的model，我认为它们的性能也应该不差。

## 0.使用要求

code文件夹中的代码需要在安装pytorch的conda环境中运行，且由于设备性能差异，output中所列数据可能与复现数据并不一致，不过差距应当很小。

## 1.结果分析

output文件夹中存放了tensorboard界面展示及程序运行结果，其中"res18\50_test"和"res16\50_testV2"这两对图片分别是数据增强改进前后的运行结果，当改进数据增强方式后，使用ResNet18达到了性能最佳，测试集上准确率高达99.31%，而ResNet50性能略差于18，可能原因是优化器和scheduler的超参数选用的是默认的18的超参数，和50略有不匹配。此外还有一部分原因是本题的各类别间差别过大，只需要浅层线条、形状、颜色特征即可分别，而ResNet50高层提取的复杂语义特征重要性不大。

## 2.数据集处理

由于题目所给的文件夹里并未明确标注测试集和训练集，所以用"SplitDir.py"程序将其划分并整理成ImageFolder格式，具体按照Train:Val:Test = 8:1:1比例划分，数据增强时Train_Set采用随机缩放、分割、裁剪，而Val_Set和Test_Set选用固定比例变换，从而提升准确率。

## 3.模型架构

本题采用ResNet18\50 + SE_Block + FC，残差网络模块用于提取图片特征，SE模块用于增强通道间注意力、整合信息，最后设计FC层是分类头，由于预训练官方参数及原网络设计是分类1000种ImageNet数据集，而本题只需分类8种，故需要改变分类头。
